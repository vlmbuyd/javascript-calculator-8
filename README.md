## 기능 요구사항 분석

### 입력

- [x]  사용자에게 문자열을 입력받는다.

### 기능

- [x]  입력받은 문자열의 모든 구분자(커스텀 구분자 포함)를 기본 구분자 `,`로 치환한다.
- [x]  치환된 문자열을 기본 구분자 `,` 를 기준으로 숫자를 추출한다.
- [x]  추출한 각 숫자를 합을 반환한다.

### 에러

- [x]  사용자가 잘못된 값을 입력했을 경우 예외 처리한다.
- [x]  `ERROR` 메시지와 함께 에러 발생
    - [x]  애플리케이션 종료 (단, `process.exit()`를 호출하여 종료하지 않는다.)
    - 발생 가능한 예외 케이스
        - [x]  커스텀 구분자를 사용하기 위한 문자 `//`, `\n`가 올바르지 않을 때 (e.g. `\t`)
        - [x]  (커스텀 구분자 외) 유효하지 않은 구분자 (e.g. ‘;’)

### 엣지 케이스

- [x]  숫자 없이 구분자만 존재 (e.g. `,`)
- [x]  비어 있는 값 (e.g. "", " ")
- [x]  숫자가 두자리 수 이상일 때
- [x]  숫자가 음수일 때
- [x]  커스텀 구분자가 한 글자가 아닐 때 (e.g. `//;ad@#;o\n`)


### 출력

- [x]  구분자를 기준으로 분리한 각 숫자의 합을 콘솔에 출력한다.
